#  Laboratorio 1: Perfil Estudiantil y Control de Versiones con GitHub

> Laboratorio de la asignatura **Sistemas Colaborativos** - Licenciatura en Ciberseguridad, Universidad Tecnológica de Panamá (UTP).

---

##  Propósito

Construir mi marca digital profesional como estudiante de primer año de Ciberseguridad, creando un perfil evolutivo en GitHub que documente mi progreso académico y mis laboratorios, y practicando el flujo básico de control de versiones (crear repositorios, editar archivos y registrar cambios con commits descriptivos).

---

##  Topología

Este laboratorio no involucra una topología de red. Se trabajó sobre un ecosistema de plataformas web interconectadas:

| Plataforma | Función |
|---|---|
| **GitHub** | Vitrina de código y documentación técnica |
| **LinkedIn** | CV digital y red de contactos profesionales |
| **Correo institucional UTP** | Identidad oficial asociada a la cuenta |

Ambos perfiles usan el mismo nombre de usuario base, para mantener una identidad coherente.

---

##  Procedimiento

1. **Configuración de la cuenta:** se configuró la cuenta de GitHub con nombre completo, ubicación (Panamá), institución (Universidad Tecnológica de Panamá) y enlace a LinkedIn.
2. **Repositorio de portada:** se creó un repositorio público con el mismo nombre del usuario, inicializado con `README.md`, que GitHub reconoce como el README especial del perfil.
3. **Plantilla Markdown:** se reemplazó el contenido del `README.md` con la plantilla oficial de las 3 áreas centrales (Importancia de la Marca Digital, Portafolio Profesional y CV en LinkedIn), personalizando mis datos.
4. **Commit descriptivo:** se registró el cambio con el mensaje `feat: inicializar perfil profesional UTP`, siguiendo la convención de mensajes de commit.
5. **Repositorio de laboratorio:** se creó este repositorio con su `README.md` explicativo, un archivo `.gitignore` y la licencia MIT.

---

##  Resultados

- Perfil de GitHub configurado con información profesional y coherente con LinkedIn.
- Repositorio de portada publicado con el README del perfil visible en la página principal.
- Repositorio de laboratorio estructurado con las buenas prácticas básicas: README descriptivo, `.gitignore` y licencia abierta (MIT).
- Historial de commits con mensajes claros que documentan cada cambio.

---

##  Estructura del repositorio

```text
.
├── README.md     # Descripción del laboratorio
├── .gitignore    # Archivos que Git debe ignorar
└── LICENSE       # Licencia MIT
```
